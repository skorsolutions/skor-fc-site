# Opponents and safe Strategy editing (Captain v58.37)

Opponents is a captain-only navigation area. Existing SKOR fixtures seed exact normalized opponent identities and game links; they do not invent scouting notes. Add a team manually or choose its linked profile. Profile names have stable IDs and aliases so a deliberate rename preserves history without merging similarly named clubs. Conflicting aliases require review.

Keep general style, strengths, weaknesses, set pieces and dangerous players on the profile. Record expected and observed formations separately against a particular game and phase. Dangerous-player notes have optional number/name, a formation role, threat and containment notes; shirt numbers may change. Each save uses an ID and expected revision, supports identical lost-response retries and rejects stale overwrites. Refresh or opening a different profile asks before discarding unsaved input. There is no delete operation.

Game Day opens scouting for its selected fixture. Profile meeting buttons return to that game. Strategy loads the exact source game's scouting; Apply scouting snapshot explicitly copies it into the draft. A changed suggested formation resets opponent placement across the draft, preserving SKOR positions. Optional dangerous-player labels attach only to matching formation roles; unmatched notes remain in the summary. Saved strategies and scene bundles retain the captured scouting, dates and suggestion provenance. Later profile updates do not mutate them. Reusing a strategy for a different opponent clears the private scouting snapshot and labels. Captain exports can contain deliberately applied labels; existing player animation shares sanitize actor fields and omit private scouting snapshots.

Formation suggestions prefer observed then expected records for the selected game. Otherwise they count at most one latest observed phase per prior meeting, across the last five eligible games; ties favor the most recent. Future, cancelled and mismatched-fixture records are excluded. Expected historical shapes never become observations; sparse/old evidence is described as such. Captains retain control over the formation.

Strategy is locked by default, including home players, opponents, ball and marks. Locked touch interaction allows page scrolling. Edit step enables movement/drawing; Finish editing commits to the local recovery draft and locks it; Cancel restores the entire step/scene before editing. Finish or cancel before adding, duplicating, navigating steps/bundles, saving, publishing or exporting. Leaving Strategy, losing focus/account context or signing out cancels unfinished movement and locks. The editable Attack / Defense baseline and both-team GIF remain available. New steps and imported plans start locked.

Lineups and Strategy offer Recommend lineup and Strategy. The authenticated generate-pregame-talk Edge Function now supports mode match_plan, fetching captain-approved opponent scouting plus exact-match eligible candidates. It excludes inactive/injured/out/absent/excused players and duplicate regular/TEMP aliases. Unknown availability is explicitly uncertain. General scouting can be opted out of AI without hiding it from captains. Existing pregame talk also receives allowed scouting and source labels. All text is untrusted context; no fabricated player skills/identities. Structured output is checked for legal roles, unique eligible identities and a keeper. Candidates are refreshed again before Apply.

Review precedes Apply. Apply lineup changes only the current local lineup draft, with guarded Undo; coaching notes stay out of public Final lineup JSON. Create Strategy makes an independent editable attack/defense baseline with private scouting snapshot and reviewed tactical points. Neither action saves shared content, changes Final nor opts a strategy into AI. Existing explicit save/publication controls still apply. An AI call is required for proposals; errors preserve originals.
